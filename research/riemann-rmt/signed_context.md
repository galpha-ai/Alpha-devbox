## 1. The three formalisms, written as one

**Level 0 (decode).** Weights w: n ∈ [N,2N) → ℝ; ν(n) = #{i : n+h_i prime} for an admissible
k-tuple H. S₁ = Σ w(n), S₂ = Σ w(n)ν(n). Classical DHL decode: if **w ≥ 0 pointwise** and
S₂ − mS₁ > 0 then some n has ν(n) ≥ m+1. If w is signed the implication FAILS: the positive excess
can be generated by w(n) < 0 at prime-poor n. Decode repair requires paying the **debt**
D := Σ_{w(n)<0} |w(n)|·(m − ν(n))₊ — either bound D directly, or (Zhang-style) support w₋ on a set
where ν is controlled by independent means (exceptional-character / bilinear estimates).

**Level 1 (divisor-sum data).** MT weights: v(n) = vector of divisor sums, w(n) = Q(v(n)) for a
quadratic form Q on λ-space. Classical MT: Q = rank-1 PSD, i.e. w = (Σ_d λ_d)². MT asymptotics make
S₁, S₂ LINEAR in Q: S₁ ~ Tr(A Q)·X, S₂ ~ Σᵢ Tr(Bᵢ Q)·X (A, B Gram forms; in the F-language these
are the I- and J-integrals). The variational constant is the generalized eigenvalue problem
M_k = sup Tr(BQ)/Tr(AQ).

**Level 2 (finite/ACUE certificates — our machinery).** All of the above have exact finite-N
